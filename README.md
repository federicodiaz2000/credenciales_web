# credenciales_web

Proyecto web de Credenciales — frontend en Flutter y backend en Python.

Repositorio generado localmente desde el proyecto existente.

Instrucciones rápidas:

- Para crear un remoto en GitHub y empujar desde la CLI:
  - Instala `gh` (GitHub CLI) y autentícate: `gh auth login`.
  - Ejecuta: `gh repo create <usuario>/credenciales_web --public --source=. --remote=origin --push`.

- Si no usas `gh`, crea el repo en GitHub y luego:
  - `git remote add origin git@github.com:<usuario>/credenciales_web.git`
  - `git push -u origin main`
